ပါဝင်သောအချက်များ
- Menu အမျိုးအစား 14 မျိုး

အရေးကြီးချက်
လက်ရှိ index.html သည် Website ဖိုင်ဖြစ်ပြီး အင်တာနက်ပေါ်တွင် Public URL မရသေးပါ။
QR Code ကို Customer များ scan လုပ်နိုင်ရန် အရင်ဆုံး Website ကို public hosting တစ်ခုသို့ တင်ပြီး URL ရယူရပါမည်။
Public URL ရရှိပြီးမှ ထို URL ကိုညွှန်းသော QR Code ကို ဖန်တီးရပါမည်။

ဈေးနှုန်းများကို ပေးပို့ထားသော Menu စာရင်းအတိုင်း ထည့်ထားပါသည်။
